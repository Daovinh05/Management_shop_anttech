# DỰ ÁN VINHZOTA - HỆ THỐNG QUẢN LÝ BÀI TẬP TRỰC TUYẾN

## 📋 TỔNG QUAN DỰ ÁN

Vinhzota là nền tảng quản lý bài tập trắc nghiệm trực tuyến, cho phép giáo viên tạo đề thi từ file và học sinh làm bài trực tuyến.

## 🗄️ CƠ SỞ DỮ LIỆU (vinhzota.sql)

### Bảng users
```sql
CREATE TABLE users (
    ma_user VARCHAR(20) PRIMARY KEY,
    ten_user VARCHAR(55) NOT NULL,
    password VARCHAR(255) NOT NULL,
    full_name VARCHAR(255),
    email VARCHAR(55),
    phone VARCHAR(20),
    school VARCHAR(255),
    avatar TEXT,
    phan_quyen ENUM('teacher', 'student') NOT NULL,
    ngay_tao DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### Bảng de_thi
```sql
CREATE TABLE de_thi (
    ma_de VARCHAR(20) PRIMARY KEY,
    ma_giao_vien VARCHAR(20) NOT NULL,
    ten_de VARCHAR(255) NOT NULL,
    ma_code VARCHAR(10) UNIQUE,
    thoi_gian_nap DATETIME,
    cho_xem_ket_qua BOOLEAN DEFAULT TRUE,
    yeu_cau_dang_nhap BOOLEAN DEFAULT FALSE,
    trang_thai ENUM('active', 'inactive') DEFAULT 'active',
    ngay_tao DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (ma_giao_vien) REFERENCES users(ma_user)
);
```

### bảng cau_hoi
```sql
CREATE TABLE cau_hoi (
    ma_cau_hoi INT AUTO_INCREMENT PRIMARY KEY,
    ma_de VARCHAR(20) NOT NULL,
    noi_dung TEXT NOT NULL,
    hinh_anh TEXT,
    thu_tự INT DEFAULT 0,
    FOREIGN KEY (ma_de) REFERENCES de_thi(ma_de)
);
```

### TABLE dap_an
```sql
CREATE TABLE dap_an (
    ma_dap_an INT AUTO_INCREMENT PRIMARY KEY,
    ma_cau_hoi INT NOT NULL,
    noi_dung TEXT NOT NULL,
    la_dung BOOLEAN DEFAULT FALSE,
    FOREIGN KEY (ma_cau_hoi) REFERENCES cau_hoi(ma_cau_hoi)
);
```

### BẢNG bai_lam
```sql
CREATE TABLE bai_lam (
    ma_bai_lam VARCHAR(20) PRIMARY KEY,
    ma_de VARCHAR(20) NOT NULL,
    ma_hoc_sinh VARCHAR(20),
    ten_hoc_sinh VARCHAR(255),
    email VARCHAR(55),
    danh_sach_dap_an TEXT,
    diem DECIMAL(5,2),
    thoi_gian_nop DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (ma_de) REFERENCES de_thi(ma_de)
);
```

### 4. Parser File Đề Thi
Format file mẫu:
```
1.Một hệ thống phân tán bao gồm hai phần chính nào?
A. Phần cứng và phần mềm.
B. Mạng máy tính và CSDL phân tán.
C. Máy chủ và máy khách.
D. Hệ điều hành và ứng dụng cơ sở dữ liệu phân tán

2.Mạng Star (hình sao) sử dụng thiết bị trung tâm nào để kết nối?
A. Modem và Switch
B. Router
C. Hub hoặc Switch.
D. Repeater.
```

Parser cần:
- [ ] Nhận diện số thứ tự câu hỏi
- [ ] Trích xuất nội dung câu hỏi
- [ ] Trích xuất 4 đáp án A, B, C, D
- [ ] Giáo viên đánh dấu đáp án đúng trên giao diện
